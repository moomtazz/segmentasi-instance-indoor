## Hipotesis

Ditulis 25-11-2026, sesudah training versi 2 dan sesudah melihat hasil di test set asli, tetapi **sebelum** evaluasi test set sendiri dijalankan. Hasil yang sudah diketahui saat menulis adalah mask mAP50-95 di test set asli, yaitu M1 0,067, M2 0,079, dan M3 0,084, serta YOLO11n-seg 0,055 pada input 320 dan 0,082 pada input 960.

| No | Hipotesis | Alasan dari arsitektur | Cara menguji |
|---|---|---|---|
| H1 | Mask R-CNN (M3) tetap unggul di test set sendiri, dengan selisih terbesar pada objek kecil seperti `mouse`, `cup`, `cell phone`, dan `bottle` | Mask R-CNN memotong fitur setiap kandidat dengan RoIAlign lalu memprediksi mask 28×28 khusus untuk objek itu, sehingga objek kecil tetap mendapat 28×28 titik. YOLO-seg menyusun mask dari prototype global beresolusi 1/4 input (160×160 untuk 640), sehingga objek kecil hanya kebagian beberapa titik prototype. Backbone R50-FPN (44 juta parameter) juga jauh lebih besar daripada YOLO nano (±3 juta) | Kolom `mask_AP_kecil` dan `ap_per_kelas.csv` pada baris `sendiri` |
| H2 | Untuk objek besar dengan tepi panjang atau bagian tipis seperti `dining table`, `chair`, dan `bed`, YOLO menyamai atau mengungguli Mask R-CNN dalam kualitas tepi mask | Grid 28×28 Mask R-CNN diperbesar ke ukuran box, sehingga untuk box besar setiap sel mewakili puluhan piksel dan kaki kursi atau tepi meja menjadi kasar. Prototype YOLO tidak bergantung pada ukuran box | `oracle_resolusi_mask.csv`, IoU oracle per kelas dan per ukuran |
| H3 | Ketiga model turun di test set sendiri dibanding test set asli dengan kelas yang sama, dengan penurunan relatif lebih dari 30%, dan penurunan terbesar terjadi pada foto laboratorium | Foto diambil dengan kamera lebar iPhone 16 rasio 16:9 dan ruangan lab dengan deretan kursi, monitor, dan PC jarang ada di data latih yang didominasi rumah, sehingga distribusi tampilan, sudut, dan susunan objek berbeda (domain shift) | `domain_shift.csv`, kolom `penurunan_relatif_%` |
| H4 | Di antara kondisi sulit, redup paling merusak, terutama karena objek terlewat (FN naik), sedangkan burem lebih banyak menurunkan kualitas tepi mask daripada jumlah deteksi | Foto redup di lab memakai ISO sampai 8000 sehingga noise tinggi dan kontras rendah, dan fitur tepi di lapisan awal CNN melemah. Burem gerak masih mempertahankan bentuk kasar objek, sehingga box masih bisa ditemukan tetapi batas mask kabur | Baris `sendiri_sulit` vs `sendiri_normal` dan `per_citra_sendiri_*.csv` |
| H5 | Mencerahkan foto redup (gamma 0,5 atau CLAHE) menaikkan TP, sedangkan memperbesar input ke 960 atau 1280 membantu objek kecil tetapi tidak membantu foto redup | Gamma dan CLAHE mengembalikan kontras yang hilang sehingga fitur tepi muncul kembali. Input lebih besar menambah piksel per objek di feature map, tetapi tidak mengurangi noise | `uji_varian_kegagalan.csv` |
| H6 | Kesalahan kelas yang paling sering terjadi adalah `teddy bear` dengan `toy`, `cabinet-merged` dengan `shelf`, dan `dining table` dengan meja belajar atau meja lab | Pasangan kelas ini mirip secara visual dan di data latih jumlah contohnya tidak seimbang, sehingga classifier cenderung memilih kelas yang lebih sering muncul | Kolom `salah_kelas` dan gambar perbandingan di bagian 5 notebook |

Jika hasilnya berbeda dari hipotesis, penjelasannya ditulis di laporan dengan merujuk tabel dan gambar yang sama.
